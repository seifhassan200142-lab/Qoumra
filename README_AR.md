# Qoumra — النسخة المعدلة

موقع ثابت يعمل على GitHub Pages بدون تثبيت مكتبات وبدون Backend. التصميم يحافظ على اللوجو والخطوط والألوان وفيديوهات الخدمات الموجودة في النسخة الأصلية.

## تشغيل الموقع

افتح `index.html` مباشرة، أو شغله من أي خادم ملفات ثابتة. ارفع الملفات والمجلدات إلى جذر مستودع `Qoumra` كما هي. كل المسارات نسبية، فتعمل تحت `/Qoumra/` بدون تعديل.

## تقسيم الملفات

| الملف / المجلد | وظيفته |
|---|---|
| `index.html` | الصفحة الأساسية، متضمنة محتوى إنجليزي جاهز للعرض |
| `css/styles.css` | تصميم الموقع، الموبايل، التابلت، العربية، والحركة |
| `css/fonts.css` | تعريف الخطوط المحلية |
| `js/config.js` | بيانات التواصل والصور والأدوات وأمثلة المشاريع |
| `js/content.js` | النصوص العربية والإنجليزية |
| `js/render.js` | قوالب الأقسام والكروت والنموذج |
| `js/app.js` | حركة اللوجو، اللغة، القائمة، المعرض والفلاتر |
| `assets/brand/` | اللوجو وحرف Q الأصليان بصيغة SVG |
| `assets/fonts/` | الخطوط المحلية |
| `assets/media/` | فيديوهات الخدمات وصور المعاينة الأصلية |
| `assets/portfolio/` | الصور الاثنتا عشرة التي ستستبدلها بصور أعمالكم |
| `scripts/build.mjs` | إعادة توليد HTML ومجلد `dist` عند الحاجة |
| `scripts/verify.mjs` | فحص اللغات والمسارات والصور والإعدادات |

## ضع الصور هنا — الأسماء الدقيقة

استبدل الملفات المؤقتة بصور JPEG حقيقية، مع المحافظة على الأسماء التالية:

| القسم | المجلد | أسماء الملفات الأربعة |
|---|---|---|
| Perfume Photography | `assets/portfolio/perfume/` | `perfume-01.jpg`, `perfume-02.jpg`, `perfume-03.jpg`, `perfume-04.jpg` |
| Food Photography | `assets/portfolio/food/` | `food-01.jpg`, `food-02.jpg`, `food-03.jpg`, `food-04.jpg` |
| Furniture Photography | `assets/portfolio/furniture/` | `furniture-01.jpg`, `furniture-02.jpg`, `furniture-03.jpg`, `furniture-04.jpg` |

- صور برفيوم زارا توضع في مجلد `perfume`؛ لم نضف ادعاء بأن Zara عميل للشركة.
- يفضل تصدير الصور بصيغة JPEG، بعرض 1200–1800 بكسل وحجم مناسب للويب. تغيير امتداد PNG إلى JPG وحده لا يحوّل الصورة.
- معاينة الكروت تقص الصورة لتناسب الإطار؛ فتح الصورة في المعرض يعرض الصورة كاملة دون قص.
- بعد إضافة الصور الحقيقية، افتح `js/config.js` وغيّر `isPlaceholder: true` إلى `isPlaceholder: false` لكل معرض اكتمل. هذا يزيل ملاحظة الصور المؤقتة ويحدّث وصفها.
- إذا استخدمت WebP أو PNG، عدّل المسار والامتداد في مصفوفة `images` داخل الإعدادات.
- عدّل `tools` ليعكس الأدوات المستخدمة فعليًا. أضفنا Photography وPhoto editing وAdobe Photoshop وفق وصفك للعمل.

## بيانات التواصل

افتح `js/config.js`، واملأ القيم الفارغة داخل `contact`:

```js
"contact": {
  "email": "",
  "phone": "",
  "facebook": "",
  "instagram": "",
  "linkedin": "",
  "tiktok": ""
}
```

اكتب روابط صفحات الشركة كاملة وتبدأ بـ `https://`. اكتب الهاتف مع رمز الدولة. القيم الفارغة تعرض اسم وسيلة التواصل وأيقونتها فقط، بدون رسالة «قريبًا» أو رابط وهمي. بمجرد وضع إيميل صحيح، يتفعل زر فتح مسودة الإيميل تلقائيًا.

النموذج يفتح تطبيق البريد لدى الزائر برسالة جاهزة، ويحتاج الزائر إلى الضغط على إرسال. لا يوجد إرسال خادمي أو تخزين للاستفسارات؛ GitHub Pages يستضيف الملفات الثابتة فقط. يمكن لاحقًا ربط خدمة إرسال حقيقية إذا رغبت.

## تعديل البورتفوليو والنصوص

- المشاريع التوضيحية موجودة في `examples` داخل `js/config.js`، ومميزة بصريًا بأنها أمثلة غير منفذة لعملاء.
- العناوين والأوصاف بالعربية والإنجليزية موجودة في `js/content.js`.
- الأقسام الرئيسية: Home، Services، Portfolio، Packages، About، Contact Us.
- تغيير اللغة يحافظ على ما كتبه الزائر في نموذج الاستفسار.
- تعمل الروابط القديمة التي تحتوي على `?reviewLocale=en` أو `?reviewLocale=ar`.

بعد تعديل النصوص، يمكن إعادة توليد HTML الثابت (اختياري لتحديث نسخة بدون JavaScript) باستخدام Node.js:

```bash
node scripts/build.mjs
node scripts/verify.mjs
```

لا تحتاج `npm install`. الموقع يعكس تعديلات ملفات JS عند إعادة تحميله حتى بدون إعادة التوليد؛ إعادة التوليد تحدث أيضًا HTML الجاهز لمحركات البحث والنسخة التي تعمل بدون JavaScript.

## الرفع إلى GitHub Pages

1. فك ضغط الحزمة.
2. افتح مستودع `seifhassan200142-lab/Qoumra`.
3. استبدل `index.html`، وأضف `css` و`js` و`assets` و`scripts` وملف `.nojekyll` والوثائق. يجب أن يكون `index.html` في جذر المستودع، لا داخل مجلد إضافي اسمه Qoumra.
4. احتفظ بإعدادات Pages الحالية إذا كانت تنشر الفرع الحالي من الجذر. لا تحتاج تغيير الدومين أو المستودع.
5. انتظر اكتمال نشر Pages، ثم افتح الرابط الحالي وأعد التحميل الكامل لتجاوز النسخة المخزنة.

لا ترفع مجلد `.openai` أو ملف `__qa.html` إن ظهر في بيئة التطوير؛ كلاهما للاختبار المحلي فقط وغير موجودين في حزمة التسليم.

## الحركة وتجربة الموبايل

تظهر كلمة Qoumra كبيرة في منتصف شاشة بلون الهوية، ثم تصغر وتتحرك إلى اللوجو في أعلى اليسار. تعمل على الكمبيوتر والموبايل، وتُختصر تلقائيًا عند تفعيل تقليل الحركة على الجهاز. عند تغيير مقاس النافذة أثناء المقدمة تنتهي الحركة بأمان. الدخول إلى رابط قسم مباشر يتجاوز المقدمة.

حرف Q يظهر كاملًا في مساحة مستقلة على الموبايل، بدون استخدام إخفاء التمرير لإخفاء مشكلة القص.

## ما يحتاج بيانات منك

- الصور الحقيقية الاثنتا عشرة.
- إيميل الشركة ورقم الهاتف وروابط الحسابات الأربعة.
- استبدال أمثلة المشاريع بأعمالكم الفعلية عندما تكون جاهزة.

## تحديث تجربة الاستخدام والنصوص

- نصوص عربية بسيطة ومباشرة، ونصوص إنجليزية تشرح الخدمة ومتى تحتاجها.
- الحفاظ على الألوان: Burgundy `#800020`، Ivory `#F8F4EC`، Charcoal `#282326`.
- تكبير النصوص الصغيرة وضبط المسافات في العربية والإنجليزية.
- حذف `Q / 01` والتعليق بجانب حرف Q وأرقام الزينة بين الأقسام.
- اختيار الخدمة حسب احتياج العميل، ثم الانتقال إلى تفاصيلها وتحديدها في نموذج الاستفسار.
- تشغيل فيديو الخدمة تلقائيًا بدون صوت عند ظهوره، وإيقافه عند مغادرة القسم أو تبويب المتصفح. يمكن النقر على الفيديو نفسه أو استخدام Enter/Space لإيقافه وتشغيله، بدون شريط تحكم ظاهر. اختيار الإيقاف اليدوي يُحترم عند التمرير.
- التشغيل التلقائي لا يعمل عند تفعيل تقليل الحركة أو توفير البيانات، وقد يمنعه المتصفح أو وضع توفير الطاقة؛ يمكن النقر على الفيديو نفسه لتشغيله. هذه القيود لا تتعلق بفتح الموقع محليًا فقط.
- الفيديوهات عبارة عن معاينات صامتة متكررة، وليست مشغلًا لفيديوهات حوارية بصوت.

الموقع يعمل بملفات ثابتة. لا يتطلب تثبيت مكتبات؛ لإعادة التوليد والفحص استخدم أوامر Node المذكورة أعلاه. لا تحتوي الحزمة على ملفات المعاينة أو الاختبارات المحلية للمتصفح.

## اللغة الافتراضية والأيقونات وحركة الظهور

- فتح `index.html` أو رابط الموقع بدون اختيار لغة يفتح الإنجليزية دائمًا، حتى لو سبق اختيار العربية. زر اللغة يبدّل للعربية، والرابط الصريح `?reviewLocale=ar` يظل يفتح العربية.
- الأيقونات مرسومة بـ SVG داخل قالب HTML؛ لا تحتاج تحميل خطوط أيقونات أو خدمات خارجية. عند التشغيل محليًا، فك ضغط الحزمة كاملة بجانب `index.html` لأن CSS وJS وباقي الوسائط ملفات منفصلة.
- حُذفت رسائل انتظار بيانات التواصل؛ تفعيل الإيميل والروابط ما زال من `js/config.js`.
- يظهر النص والكروت تدريجيًا عند دخول الشاشة في النزول والصعود. لا يتغير طول الصفحة ولا سرعة السكرول. المحتوى يظهر بشكل عادي عند تقليل الحركة أو عدم توفر JavaScript، ويظل متاحًا لقارئ الشاشة والتنقل بالكيبورد والطباعة.
